# Abstract

Neural simulation studies span multiple scales, yet pipeline-stage relationships follow per-tool convention rather than explicit contract, leaving claim boundaries hard to verify. We describe jaxfne, a JAX-native simulator whose pipeline is factorized into typed stages — dynamics, source, field, probe — each carrying ownership and disablement contracts, and every reported quantity declared relative or calibrated. Extensions of the classical emitter obey a reduction identity: restoring the neutral written state, removing delays, or disabling observations exactly recovers the base semantics. Registered deterministic validation, with negative and unresolved outcomes reported as such, found no traveling waves across preregistered geometries and delay policies using an estimator validated on synthetic controls only; reported a candidate adaptation phenotype as attenuation, not adaptation; and demonstrated propagation of a written state through an existing hierarchical feedback pathway. A closed-loop region remains unresolved. Figures come from a single frozen, hash-gated evidence set reproducible from a clean checkout.
