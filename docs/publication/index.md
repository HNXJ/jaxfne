# Publication

Results from jaxfne publication experiments are collected and presented here as
they are produced. Nothing in this section constitutes a physical-validity claim;
every value is **Relative** unless produced through an explicit, evidenced
calibration step, and the standard truth gates apply throughout:

- `claim_level = computational_scaffold`
- `field_solver_status = linear_solver`
- `field_claim_level = proxy_readout`
- `physical_amplitude_calibrated = False`
