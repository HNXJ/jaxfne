### 3. Plasticity Numerics: Implement Bounded Homeostatic Update

**Current state:** Config only; no numerical update
```python
plasticity_config = {
    "mode": "global_on",
    "homeostatic_rule": "low_rate_potentiation_high_rate_depression",
    "target_rate_hz": 10.0,
    "weight_bounds": "preserve_sign",
    "eta_homeo": 0.01,
}
```

**Required fix:** Implement bounded segment-boundary update
- At each segment boundary (prefix → d1, d1 → d2, d2 → d3, d3 → d4, d4 → review):
  - Measure mean firing rate over recent window (100 ms default)
  - Compute plasticity delta: ± η × (observed_rate - target_rate) / target_rate
  - Update weights: w_new = w_old × (1 + delta), clipped to ±1
  - Preserve excitatory (+) and inhibitory (−) signs
- Verify: weights remain in [−1, 1], signs preserved, rates approach target

**Test:** Plasticity convergence
- Run 4000 ms (multiple segments), measure firing rate each segment
- Assert: rates converge toward 10 Hz over segments 1-4
- Assert: weights remain in bounds
- Assert: E/I signs preserved

**Files to change:**
- `jaxfne/sanity_delta.py`: Add plasticity kernel (segment-boundary update)
- `jaxfne/sanity_delta.py`: Integrate into run_task() (call after segment boundary)
- Add test: `tests/test_sanity_delta_plasticity_numerics.py`

**Effort:** 25-40 hours
