- The adex route realizes per-type AdEx cell parameters through `cell_params`: one scalar per cell type for the kernel fields (`C_pF`, `gL_nS`, `EL_mV`, `VT_mV`, `Delta_mV`, `Vreset_mV`, `tauw_ms`, `a_nS`, `b_pA`, `Tref_ms`, `Vpeak_mV`). Izhikevich keys stay on the Izhikevich route. Values outside the kernel's physical range (`C_pF`, `gL_nS`, `tauw_ms` above 0; `Tref_ms`, `Delta_mV` at or above 0) are refused; an `EL_mV` above `VT_mV` is a valid tonically firing regime and is realized.
