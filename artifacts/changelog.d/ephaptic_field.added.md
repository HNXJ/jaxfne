- Registered HDP rule `ephaptic_field` (`jaxfne.hdp_rules_ephaptic`): endogenous ephaptic coupling \(\Phi_i=\alpha\sum_j M_{ij}(v_j-v_{\mathrm{rest}})\) on the Izhikevich and LIF routes, entering the membrane through `drive_bias` at the next step (from post-step voltages on LIF, pre-step voltages on Izhikevich). `ephaptic_kernel` builds a sparse Gaussian kernel \(M\) from positions (cutoff, optional row normalization; coincident positions give no pair, and a row whose weights all underflow stays 0); cost scales with kernel pairs, never \(N^2\). \(\alpha=0\) reproduces the uncoupled run on the same backend (through `simulate()`, the rule-free run with `recurrent_backend="edge_list"`; an engaged rule always runs the edge-list kernel, ISSUE_LOG P-062). Without the rule nothing changes.
