- Declared input sources: `XSource` in `jaxfne.inputs` (ADVANCED), a frozen record of one configured external input of kind `"constant"` (a per-neuron value with units) or `"poisson"` (a rate with seed and schedule). `Model.x_sources` is a read-only view derived at access from the realized drive, grouped by final area, layer and cell type with neuron counts, so it tracks parameter edits, tuning and composition. Run and model manifests emit one `x_sources` vocabulary plus the run Poisson rows.
