- Simulation receipts report the jit decision the kernel used (`runtime.jit`). Under the default `auto` policy a small run reports `false` and a run above the threshold reports `true`; `jaxfne.runtime_report()` made outside a run reports `None` under `auto`. The requested policy is in the new `jit_policy` key, and a policy given as the string `"false"` reports `false` (it read `true`).
