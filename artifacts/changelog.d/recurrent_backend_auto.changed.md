- `RuntimeConfig.recurrent_backend` (and `jtfne.runtime()`, `suite2_simulation()`, `default_cortical_column_config()`) now defaults to `"auto"`, which selects the backend the run needs: edge_list under homeostasis, an engaged HDP rule (any `enable_hdp` in `simulate_batch()`), a model whose edges live only in `params["edge_list"]`, the receptor kernel, `connections()` rule edges, finite edge delays and full-state continuation, and on the lif, rate and adex routes; dense otherwise. Any value other than `"auto"`, `"dense"` or `"edge_list"` is rejected by `RuntimeConfig` and `Configuration.runtime()`. Default runs that succeeded before give the same spikes, voltages and state. Runs that refused the old default now run. An explicit `RuntimeConfig(recurrent_backend="dense")` under homeostasis, HDP or a model whose edges live only in `params["edge_list"]`, which used to run edge_list silently, is now refused; an explicit `RuntimeConfig(recurrent_backend="edge_list")` now runs where a model-level `runtime(recurrent_backend="dense")` used to refuse it. The lif, rate and adex routes now record `recurrent_backend: "edge_list"` in their run metadata. The runtime report records the requested `"auto"`, so receipt IDs of default runs change (ISSUE_LOG P-062).
