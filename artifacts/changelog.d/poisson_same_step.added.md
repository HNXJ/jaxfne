- `Simulation(poisson_drive=...)` on the AdEx route gains the optional key `"same_step": True`, admitting a drive `delay_ms` that rounds to 0 steps so each drawn count acts in the step it is drawn. A sub-step drive delay without the flag is refused, as before; `"same_step": True` with a delay reaching 1 step or more, or with `step_order="brian2"`, is refused. The run metadata records `"same_step": True` when the flag is set.
