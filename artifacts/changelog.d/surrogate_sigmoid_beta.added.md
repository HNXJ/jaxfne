- `RuntimeConfig(surrogate=SurrogateConfig(method="sigmoid_beta", beta=...))` carries the gradient across neurons on the dense Izhikevich default-order route: the spike is emitted through `jaxfne.emitters.spike_sigmoid_beta` (hard spike forward, derivative `beta s (1 - s)` with `beta` in 1/mV), so the backward pass runs `Wᵀ`; forward outputs are bit-identical, the reset stays detached, and every other route, every method except `sigmoid_beta` and a `beta` at or below 0 refuse the surrogate by name (P-052).
