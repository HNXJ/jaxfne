# artifacts/

Internal coordination and archived material for jaxfne development. **Not part of the
installable PyPI package** (excluded from the wheel/sdist via `pyproject.toml`).

| Path | Purpose |
|------|---------|
| `developer/` | Local-only developer working notes — gitignored, not present in a fresh clone |
| `legacy/` | Frozen pre-0.4.x notebooks, internal docs, and scratch archives (moved from root `.legacy/` 2026-07-11) |
| Other subdirs | Evidence bundles, import-cost snapshots, release receipts — session-scoped |

Contributors: see [docs/contributing.md](../docs/contributing.md). Agent workflows: [docs/for_ai_agents.md](../docs/for_ai_agents.md).
