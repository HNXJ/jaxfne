## P-053: sparse-weight learning divergence

Issue ledger reports identical spikes with ~0.4% simple weight divergence on an unavailable 60-event sparse fixture. The dense R3 chain passed at rtol 1e-12; this does not cover sparse initial weights.

Oracle `pcl_event_ref.py::weight_update_simple` updates each addressed weight in event-buffer order, recomputes the pre-update weight for each repeated address, clips negatives after each buffer entry, then L1-normalizes the whole simple weight tensor. The inhibitory top-down and lateral rows have separate update and normalization rules. Complex plasticity has different pair-order and clipping behavior.

Core `run_tuning.py::run_core_events` delegates plasticity to `pcl_buffer_stdp`; `_core_w_update` passes independent simple/complex constants and `_core_tables` supplies the continued weights. The consumer-level scan implementation must be inspected before attributing an ordering defect.

Minimal diagnostic, not yet run:
1. Construct the smallest permitted topology with two distinct event addresses and one repeated address, all-zero weights except one nonzero element; include both lateral and top-down routes.
2. Freeze event timestamps, polarities, neuron identity, update mode, initial weights, dtype=float64, and all RNG domains. Include a positive case known to update a weight, a null case with learning disabled, and a dense nonzero control.
3. Compare oracle and core at each event boundary: spike ids/times, event buffers, last-spike time, simple/complex weights, inhibitory weights, and pre/post normalization sums. The first differing state and event are the estimand.
4. Repeat with distinct timestamps versus ties, repeated versus unique addresses, and exact zeros versus epsilon-positive weights. Change only one factor at a time.
5. Accept exactness only if the declared per-state tolerance holds on all cases; otherwise preserve the minimal failing input and classify the first divergence. Do not infer causality from terminal weight differences.

## P-056: deep-layer LFP deficit

The pilot reports deep power <0.5% of L2/3 power, with no deep alpha-beta peak. `jaxfne/fields/kernel_lfp.py` computes a passive-cable, line-source hybrid field from class-weighted spike counts and class kernels; it does not generate oscillations.

At frequency f, the full complex field is Phi(f)=sum_c K_c(f) S_c(f). Power is sum_{c,d} K_c(f) conj(K_d(f)) P_cd(f). Consequently weak deep power may arise from insufficient presynaptic drive, small deep transfer, or cancellation/coherence, and cannot be attributed from the aggregate ratio alone.

Minimum discriminators, pending the pilot inputs:
1. Define contacts, deep/L2/3 bands, reference, windowing, units, trial selection, and baseline power denominator before comparison.
2. Measure presynaptic rates, spectra and within/cross-layer coherence for each source class.
3. Measure |K_c(f)| and class-specific field contributions at deep contacts, with all source trains held fixed.
4. Compute auto- and cross-spectral terms and the residual against the full synthesized spectrum. Shuffle phase across classes as a cancellation control; preserve within-class spike counts.
5. Perturb one factor at a time: deep source rate, kernel geometry/amplitude, coherence radius. Compare normalized and absolute power. Preserve failures and distinguish numerical forward-model checks from biological spectrolaminar validation.
